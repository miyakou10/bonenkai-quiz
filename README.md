# 忘年会クイズ（固定QR版）

## 今回の仕様

- テーブルに置いたQRコードを全員が読み取る
- QRコードのリンクは `player.html` 固定
- 全員が同じFirebaseの `rooms/bonenkai` に参加
- 管理者は `admin.html`
- 管理者画面で参加者をリアルタイム確認
- 問題終了後、「一つ前の問題の全員の回答」を管理者画面に表示
- Firebase設定は `admin.html` と `player.html` のHTML内に直接記載
- 管理者側でQRコードを生成する必要なし

## テーブル用QRコード

Web公開後の参加URL：

`https://あなたのドメイン/player.html`

このURLをQRコード化して印刷し、テーブルに置いてください。

例：
- 全テーブル同じQR → 全員が同じゲームに参加
- QRを1枚だけ大きく印刷して会場入口に置く → 同じく全員参加

## 管理者

`admin.html` を幹事PC・プロジェクターで開きます。

できること：
1. 参加者一覧
2. 第1問開始
3. 回答済み人数確認
4. 回答締め切り
5. 一つ前の問題の全員の回答確認
6. 次の問題へ
7. ゲームリセット

## Firebase設定

FirebaseのWeb設定はHTML内の `<script type="module">` に直接記載しています。
ご提示いただいた設定をそのまま使用しています。

## Realtime Databaseルール

試作では `firebase-rules.json` のような公開ルールを使用できます。

ただし、本番利用では認証・Security Rulesを設定してください。
この試作のルールのままインターネット公開するのはおすすめしません。

## 問題変更

`admin.html` の `QUIZ_DATA` を変更してください。

`answer` は0始まり：
A=0 / B=1 / C=2 / D=3

## 注意

回答時間は参加者端末の時計を基準にしています。
本番版ではFirebaseサーバー時刻を使った計測に変更すると、端末時計の差に強くできます。
